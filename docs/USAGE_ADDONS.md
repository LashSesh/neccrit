# Using addons (short)

Default: disabled. To enable:
1. Run: python tools/enable_addons.py
2. Confirm text exactly when prompted.

To enable steganography:
1. Ensure addons are enabled.
2. Run: python tools/enable_stegano.py
3. Confirm second explicit phrase.

Build core artifact:
./scripts/build-core.sh

Build research artifact (contains addons):
./scripts/build-research.sh

Responsible use: Do not use these features to facilitate illegal activity. Keep local audit logs and user consent.
